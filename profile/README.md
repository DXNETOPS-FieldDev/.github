# DX NetOps Field Development

DX NetOps related enhancements and customizations built by the field team — App Views, Grafana dashboards, and utilities for DX NetOps Performance Center, Spectrum, and AppNeta.

## Projects

- **[WeatherMap](https://github.com/DXNETOPS-FieldDev/WeatherMap)** — DX NetOps Performance Center App View with an interactive weather map: SD-WAN tunnels, AppNeta Monitoring Points, and Spectrum alarms.
- **[grafana-operational-reports](https://github.com/DXNETOPS-FieldDev/grafana-operational-reports)** — Grafana dashboards migrated from CABI Operational Reports for DX NetOps Spectrum.
- **[grafana-netops-flow-reports](https://github.com/DXNETOPS-FieldDev/grafana-netops-flow-reports)** — Grafana dashboards for NetOps flow/conversation traffic reporting.
- **[ThresholdReport](https://github.com/DXNETOPS-FieldDev/ThresholdReport)** — Threshold reporting for DX NetOps.
- **[Device-Geo-Editor](https://github.com/DXNETOPS-FieldDev/Device-Geo-Editor)** — Editor for device geo-location data.
